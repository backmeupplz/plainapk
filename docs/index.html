Plain APK

Apps straight from their releases, updated while you sleep.

Plain APK is a small Android app store that installs apps directly from the developer's GitHub, Forgejo or GitLab releases and keeps them up to date in the background, even when a project ships a new build every hour.

Plain APK is being built in the open right now, so there is nothing to install yet. Follow along on Forgejo or the GitHub mirror.

How it works

You paste a repository link or pick an app from the catalogue, and Plain APK downloads the APK the developer attached to their latest release. Before installing anything it checks that the package name matches and that the app is signed by the same key as before, so a swapped file never reaches your phone.

It also looks at the apps you already have and offers to keep the ones it can match to a public repository up to date. On Android 12 and newer, updates for apps it installed happen silently in the background, including updates to Plain APK itself, and it works the same on GrapheneOS and other phones without Google services.

Nothing in the middle

There is no server, no account and no analytics. The catalogue is a list of apps in a public git repository that anyone can extend with a pull request, and your phone talks to the code forges directly, keeping everything it learns on the device.

For developers

If your releases already have an APK attached, your app works with Plain APK today and you don't need to change anything. Make sure every build has a higher versionCode than the last one and is signed with the same key, and you can release as often as you like.

An optional file in the root of your repository covers the rest:

# .plainapk.yml
asset: "app-*-release.apk"  # which file to pick when a release has several
prerelease: false            # set to true to ship prereleases too
signer: "ab:cd:…"            # SHA-256 of your signing certificate
